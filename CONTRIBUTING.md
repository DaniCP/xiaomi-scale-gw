# Contributing

Thanks for your interest! This is a personal project published as-is, and **it does not accept pull requests**.

- **Want to change something?** Fork the repository and adapt it freely (MIT license).
- **Found a bug or tested another scale/region?** You can open an Issue with the details (never paste your `config.json`, tokens or bindkey). Answers are not guaranteed.

---

Este es un proyecto personal publicado tal cual y **no acepta pull requests**. Si quieres cambiar algo, haz un fork y adáptalo libremente (licencia MIT). Puedes abrir un Issue para informar de errores o de pruebas con otras básculas o regiones, sin pegar nunca tu `config.json`, tokens ni bindkey.
